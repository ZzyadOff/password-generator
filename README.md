# Password Generator

A basic graphical password generator built in Python using **Tkinter**.

---

## Features

* **Customizable Length**: Adjustable password length (6 to 32 characters) using an interactive slider.
* **Character Options**: Toggle Uppercase (`A-Z`), Lowercase (`a-z`), Numbers (`0-9`), and Symbols (`!@#$`).
* **Strength Indicator**: Real-time evaluation of password strength (Weak, Medium, Strong).
* **Clipboard Integration**: One-click copy button with temporary visual feedback.
* **Dark Interface**: Minimalist dark mode layout matching standard dark themes.

---

## Technologies

* **Python 3.x**
* **Tkinter** (Standard GUI library)
